## Overview

Use Datepicker for single dates, ranges, or multiple dates. It combines [Vanilla Calendar Pro](https://vanilla-calendar.pro/) with Bootstrap’s popup positioning, focus, and events.

Start with a button to open the calendar without showing a mobile keyboard. Put the button label in a span with `data-bs-datepicker-display`. Datepicker updates that span and restores the label when you clear the selection.

<Example code={`<button type="button" class="btn-solid theme-primary justify-content-start" id="datepicker1" aria-labelledby="datepicker1Label datepicker1Value" data-bs-locale="en-US" data-bs-date-format='{"month":"2-digit","day":"2-digit","year":"numeric"}' data-bs-toggle="datepicker">
    <span class="visually-hidden" id="datepicker1Label">Appointment date</span>
    <svg class="bi" width="16" height="16" aria-hidden="true"><use href="#calendar-week" /></svg>
    <span id="datepicker1Value" data-bs-datepicker-display>Choose a date…</span>
  </button>`} />

## How it works

- Add `data-bs-toggle="datepicker"` to a button or text input.
- A single date or completed range closes the popup. Multiple-date selection keeps it open. Closing a popup with an unfinished range restores the previous selection.
- Click outside or press <kbd>Escape</kbd> to close it.
- Use an [input with a calendar button](#input-with-calendar-button) for typing. See [Form submission](#form-submission) for ISO values and reset behavior.

### Custom date formatting

Control how dates are displayed using the `dateFormat` option. Pass an [`Intl.DateTimeFormat` options object](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/DateTimeFormat#options) or a custom function.

```js
// Using Intl.DateTimeFormat options
const datepicker = new bootstrap.Datepicker(element, {
  dateFormat: { month: 'short', day: 'numeric', year: 'numeric' }
  // Output: "Dec 23, 2026 – Dec 28, 2026"
})

// Using a custom function
const customDatepicker = new bootstrap.Datepicker(element, {
  dateFormat: (date, locale) => {
    return date.toLocaleDateString(locale, { month: 'short', day: 'numeric' })
  }
  // Output: "Dec 23 – Dec 28"
})
```

Formatter results are inserted as text, including strings that contain HTML. Formatting changes the display, not the submitted ISO dates.

## Dark mode

The datepicker automatically adapts to Bootstrap’s color modes. When `data-bs-theme="dark"` is set on a parent element or the `<html>` tag, the calendar popup inherits that theme.

### Inherited from parent

When a parent element has a theme, both the input and calendar popup inherit it:

<Example code={`<div data-bs-theme="dark" class="p-3 bg-body fg-body rounded">
    <label for="datepickerDark" class="form-label">Dark mode datepicker</label>
    <input type="text" class="form-control" id="datepickerDark" data-bs-toggle="datepicker" autocomplete="off" placeholder="Select a date">
  </div>`} />

### Datepicker-only theme

Use `data-bs-datepicker-theme` to set the datepicker popup’s theme independently of the input. This is useful when you want a light input with a dark datepicker, or vice versa:

<Example code={`<label for="datepickerTheme" class="form-label">Light input, dark datepicker</label>
  <input type="text" class="form-control w-12" id="datepickerTheme" data-bs-toggle="datepicker" autocomplete="off" data-bs-datepicker-theme="dark" placeholder="Select a date">`} />

## Shadow DOM

When the trigger is inside a shadow root, the calendar stays in that root. Two things differ from normal use:

- Initialize the datepicker with JavaScript. Delegated events re-target at the shadow boundary, so `data-bs-toggle="datepicker"` does not reach elements inside a shadow root.
- Adopt Bootstrap’s stylesheet into the shadow root. Document styles do not cross the boundary, so the calendar renders unstyled without it.

```js
const sheet = new CSSStyleSheet()
sheet.replaceSync(await (await fetch('/path/to/bootstrap.min.css')).text())

const root = host.attachShadow({ mode: 'open' })
root.adoptedStyleSheets = [sheet]
root.innerHTML = '<input type="text" id="shadowDatepicker">'

new bootstrap.Datepicker(root.getElementById('shadowDatepicker'))
```

## Accessibility

Give each input an associated label. Give icon-only calendar buttons an accessible name. Button triggers focus the selected date or today. If neither is available, focus moves to an enabled calendar control.

When an input opens the popup, <kbd>Tab</kbd> enters its controls. After the last control, <kbd>Tab</kbd> closes the popup and continues after the opening control. <kbd>Shift</kbd>+<kbd>Tab</kbd> from the first control returns to the opening control. <kbd>Escape</kbd> and date selection also return focus there. Hidden calendars do not receive keyboard focus.

Use arrow keys to move by day or week. Use <kbd>Home</kbd> and <kbd>End</kbd> to go to the start or end of a week. <kbd>Page Up</kbd> and <kbd>Page Down</kbd> move by month. Hold <kbd>Shift</kbd> to move by year. The popup uses the field’s label, and the calendar announces when the next step is to choose an end date.

The popup fades and scales like Menu. It skips motion when reduced motion is enabled.

The popup uses the browser’s top layer, including inside dialogs. It stays within the viewport and scrolls its own content when needed. Opening it does not lock page scrolling or change the page width.

## Usage

### Form submission

Give the input a `name` and an ISO initial value. Try typing an invalid date and submitting the form. The input displays a localized date and submits `YYYY-MM-DD`. Reset restores the initial selection.

<Example code={`<form>
    <div class="form-field w-12">
      <label for="datepickerSubmit" class="form-label">Departure date</label>
      <input type="text" class="form-control" id="datepickerSubmit" name="departure" value="2026-10-05" data-bs-toggle="datepicker" data-bs-locale="en-GB" autocomplete="off">
    </div>
    <div class="d-flex gap-2 mt-3">
      <button type="submit" class="btn-solid theme-primary">Submit</button>
      <button type="reset" class="btn-outline theme-secondary">Reset</button>
    </div>
  </form>`} />

Multiple dates and ranges submit comma-separated ISO dates. An empty selection submits an empty string. Disabled fields are omitted. Always validate submitted dates on your server.

Button triggers do not submit dates. Use a named input, or copy `getSelectedDates()` into your form.

<details>
  <summary>Input parsing and form behavior</summary>

  Manual input accepts ISO dates and numeric dates that match the picker’s locale format, with ASCII digits and a four-digit year. Month names, custom formatter output, and multiple-date text are not parsed. Invalid input and unavailable dates clear the selection. The typed text stays visible and blocks form submission until you correct it. Datepicker shows an error when the field loses focus or fails form validation. Use a read-only field or button for ranges and multiple dates.

  Prefilled inputs initialize on page load. Empty inputs initialize on focus, or on page load when they have a separate calendar button. Initialize an empty field explicitly if you need its form binding before focus.

  Use `getSelectedDates()` to read ISO values. Form submission and `new FormData(form)` also use ISO values. Do not query the generated hidden input. If you move the input between forms, dispose and initialize the picker again.

  `dispose()` preserves the input and its listeners, restores its name, and removes the picker’s form binding. The input then submits its visible value. A canceled reset leaves the selection unchanged and does not cancel an earlier completed reset.
</details>

### Advanced configuration

For supported settings not exposed by Bootstrap’s options, use `vcpOptions`:

```js
const datepicker = new bootstrap.Datepicker(element, {
  vcpOptions: {
    disableDatesPast: true,                     // Disable past dates
    disableWeekdays: [0, 6],                    // Disable weekends
    disableDates: ['2026-12-25', '2026-12-26'], // Disable specific dates
    selectedHolidays: ['2026-01-01']            // Highlight holidays
  }
})
```

See the [Vanilla Calendar Pro documentation](https://vanilla-calendar.pro/docs/reference/settings) for available settings. Bootstrap overrides input mode, placement, themes, extensions, and its initialization, update, and date-click callbacks to keep its public behavior consistent.

Vanilla Calendar Pro templates, including `layouts`, contain trusted HTML. Do not populate them with untrusted content or user-supplied JSON. This also applies to templates inside `data-bs-vcp-options`. Bootstrap does not sanitize these templates. Use formatter functions for plain text.

Vanilla Calendar Pro ships its optional features as extensions. Bootstrap uses only the `months` extension, which `displayMonthsCount` needs. Options from other extensions are not supported, and Vanilla Calendar Pro throws an error when you set them. These include `animation`, `enableSwipe`, `selectionTimeMode`, `popups`, and the week view options.

### Methods

<BsTable>
| Method | Description |
| --- | --- |
| `show()` | Opens the calendar. Returns a promise that resolves after the opening transition. |
| `hide()` | Closes the calendar. Returns a promise that resolves after the closing transition. |
| `toggle()` | Opens or closes the calendar. Returns a promise that resolves after the transition. |
| `getSelectedDates()` | Returns an array of selected dates in `YYYY-MM-DD` format |
| `setSelectedDates(dates)` | Sets the selected dates and updates the display. Accepts an array of ISO date strings. Does not fire `change.bs.datepicker`. |
| `dispose()` | Destroys the datepicker instance |
| `getInstance(element)` | Static method to get the datepicker instance from a DOM element |
| `getOrCreateInstance(element)` | Static method to get or create a datepicker instance |
</BsTable>

### Events

<BsTable>
| Event | Description |
| --- | --- |
| `show.bs.datepicker` | Fires immediately when the `show` method is called |
| `shown.bs.datepicker` | Fires after the opening transition. |
| `hide.bs.datepicker` | Fires immediately when the `hide` method is called |
| `hidden.bs.datepicker` | Fires after the closing transition. |
| `change.bs.datepicker` | Fires after calendar selection changes. Includes `dates` (ISO date array) and `event` (the original click). Typing and `setSelectedDates()` do not fire it. |
</BsTable>

```js
const datepickerEl = document.getElementById('myDatepicker')
datepickerEl.addEventListener('change.bs.datepicker', event => {
  console.log('Selected dates:', event.dates)
})
```
