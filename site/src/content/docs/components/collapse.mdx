## How it works

Collapse uses `<details class="collapse">` to show and hide content. A visible `<summary>` works with the keyboard without JavaScript. Add `open` to show the content on first paint. Put any padding on the content inside the disclosure.

Bootstrap’s JavaScript adds external controls, hash links, and the Collapse methods and events.

Vertical animation needs [`interpolate-size`](https://developer.mozilla.org/en-US/docs/Web/CSS/interpolate-size). Browsers without it open and close vertical panels at once. See [Transitions]([[docsref:/customize/transitions]]) to change the timing or to remove it.

<Callout name="info-prefersreducedmotion" />

## Example

External controls use `data-bs-toggle="collapse"` and a selector in `data-bs-target` or `href`. Add `hidden` to the summary when the external controls provide the only way to toggle the panel.

<Example code={`<p class="d-inline-flex gap-1">
    <a class="btn-solid theme-primary" data-bs-toggle="collapse" href="#collapseExample" role="button" aria-expanded="false" aria-controls="collapseExample">
      Link with href
    </a>
    <button class="btn-solid theme-primary" type="button" data-bs-toggle="collapse" data-bs-target="#collapseExample" aria-expanded="false" aria-controls="collapseExample">
      Button with data-bs-target
    </button>
  </p>
  <details class="collapse" id="collapseExample">
    <summary hidden>More information</summary>
    <div class="card card-body">
      Some placeholder content for the collapse component. This panel is hidden by default but revealed when the user activates the relevant trigger.
    </div>
  </details>`} />

Leave the summary visible to toggle the content without JavaScript.

<Example code={`<details class="collapse">
    <summary>More information</summary>
    <div class="card card-body">The summary stays visible while the content is closed.</div>
  </details>`} />

## Horizontal

Add `.collapse-horizontal` to animate the width of the content. Set a width on the content so it keeps its layout as the grid track expands. A visible summary sets the minimum width of the disclosure. Use a style or one of our [width utilities]([[docsref:/utilities/width]]).

The plugin keeps the `open` attribute until a horizontal close transition ends. External controls update their expanded state when the transition starts.

<Callout>
Please note that while the example below has a `min-height` set to avoid excessive repaints in our docs, this is not explicitly required. **Only the width on the content is required.**

WebKit can shrink a vertical disclosure to its closed height before the content transition ends.
</Callout>

<Example code={`<p>
    <button class="btn-solid theme-primary" type="button" data-bs-toggle="collapse" data-bs-target="#collapseWidthExample" aria-expanded="false" aria-controls="collapseWidthExample">
      Toggle width collapse
    </button>
  </p>
  <div style="min-height: 140px;">
    <details class="collapse collapse-horizontal" id="collapseWidthExample">
      <summary hidden>Horizontal panel</summary>
      <div class="card card-body" style="width: 300px;">
        This is some placeholder content for a horizontal collapse. It’s hidden by default and shown when triggered.
      </div>
    </details>
  </div>`} />

## Groups

Use `name` for browser-managed groups that work without JavaScript. The browser closes a named peer and emits a native `toggle` event. Use `data-bs-parent` for groups that need cancellable Bootstrap events or shared triggers.

## Multiple toggles and targets

A `<button>` or `<a>` element can show and hide multiple elements by referencing them with a selector in its `data-bs-target` or `href` attribute.
Conversely, multiple `<button>` or `<a>` elements can show and hide the same element if they each reference it with their `data-bs-target` or `href` attribute.

<Example code={`<p class="d-inline-flex gap-1">
    <a class="btn-solid theme-primary" data-bs-toggle="collapse" href="#multiCollapseExample1" role="button" aria-expanded="false" aria-controls="multiCollapseExample1">Toggle first element</a>
    <button class="btn-solid theme-primary" type="button" data-bs-toggle="collapse" data-bs-target="#multiCollapseExample2" aria-expanded="false" aria-controls="multiCollapseExample2">Toggle second element</button>
    <button class="btn-solid theme-primary" type="button" data-bs-toggle="collapse" data-bs-target=".multi-collapse" aria-expanded="false" aria-controls="multiCollapseExample1 multiCollapseExample2">Toggle both elements</button>
  </p>
  <div class="row">
    <div class="col">
      <details class="collapse multi-collapse" id="multiCollapseExample1">
        <summary hidden>First panel</summary>
        <div class="card card-body">
          Some placeholder content for the first collapse component of this multi-collapse example. This panel is hidden by default but revealed when the user activates the relevant trigger.
        </div>
      </details>
    </div>
    <div class="col">
      <details class="collapse multi-collapse" id="multiCollapseExample2">
        <summary hidden>Second panel</summary>
        <div class="card card-body">
          Some placeholder content for the second collapse component of this multi-collapse example. This panel is hidden by default but revealed when the user activates the relevant trigger.
        </div>
      </details>
    </div>
  </div>`} />

## Hash links

Hash links also work when Bootstrap loads after the page. A later fragment change cancels an earlier target’s pending scroll.

Add `data-bs-hash` to a collapsible target to open it when the URL fragment matches its `id`. Use a normal in-page link (without `data-bs-toggle`) to try it. You may need to use `scroll-margin-block-start` for some viewport offsetting if using a stickied or fixed navbar.

<Example code={`<p class="d-inline-flex gap-1">
    <a class="btn-outline theme-primary" href="#collapseHashExample">Open via hash link</a>
    <button class="btn-solid theme-primary" type="button" data-bs-toggle="collapse" data-bs-target="#collapseHashExample" aria-expanded="false" aria-controls="collapseHashExample">
      Toggle
    </button>
  </p>
  <details class="collapse" id="collapseHashExample" data-bs-hash>
    <summary hidden>Hash-linked panel</summary>
    <div class="card card-body">
      <p>Some placeholder content for a hash-linked collapse. Visiting <code>#collapseHashExample</code> opens this panel and scrolls it into view.</p>
    </div>
  </details>`} />

## Accessibility

The browser exposes the summary’s expanded state. For an external control, set `aria-expanded` to match the initial state of its targets. The plugin keeps this value in sync. Set `aria-controls` to the target IDs. If you use a link as a control, add `role="button"`.

Note that Bootstrap’s current implementation does not cover the various *optional* keyboard interactions described in the [ARIA Authoring Practices Guide accordion pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/) - you will need to include these yourself with custom JavaScript.

## Usage

Add `.collapse-instant` or `.transition-none` to open and close at once. The plugin uses the computed CSS transition timing before it fires `shown.bs.collapse` or `hidden.bs.collapse`.

### Via data attributes

Add `data-bs-toggle="collapse"` and a `data-bs-target` selector to an external control. The selector can match one or more `<details class="collapse">` elements.

<BsTable>
| Attribute | Description |
| --- | --- |
| `data-bs-toggle="collapse"` | Initializes the collapse plugin on the trigger element. |
| `data-bs-target` | CSS selector for the element(s) to expand and collapse. |
| `data-bs-parent` | When set on the collapsible element, closes sibling collapses under the same parent (accordion behavior). |
| `data-bs-hash` | When set on the collapsible target, opens that collapse when the URL fragment matches its `id` (on load and `hashchange`). See [Hash links](#hash-links). |
</BsTable>

### Via JavaScript

Enable manually with:

```js
const collapseElementList = document.querySelectorAll('details.collapse')
const collapseList = [...collapseElementList].map(collapseEl => new bootstrap.Collapse(collapseEl))
```

### Methods

<Callout name="info-promise-methods" />

Activates your content as a collapsible element. Accepts an optional options `object`.

The constructor keeps the state that your markup declares. Add `open` to start open. Call `show()`, `hide()`, or `toggle()` to change the state.

```js
const bsCollapse = new bootstrap.Collapse('#myCollapse')
bsCollapse.show()
```

<BsTable>
| Method | Description |
| --- | --- |
| `dispose` | Destroys an element’s collapse. (Removes stored data on the DOM element) |
| `getInstance` | Static method which allows you to get the collapse instance associated to a DOM element, you can use it like this: `bootstrap.Collapse.getInstance(element)`. |
| `getOrCreateInstance` | Static method which returns a collapse instance associated to a DOM element or create a new one in case it wasn’t initialized. You can use it like this: `bootstrap.Collapse.getOrCreateInstance(element)`. |
| `hide` | Hides a collapsible element. **Returns a promise that resolves once the collapsible element is hidden** (i.e. after the `hidden.bs.collapse` event fires). |
| `show` | Shows a collapsible element. **Returns a promise that resolves once the collapsible element is shown** (i.e. after the `shown.bs.collapse` event fires). |
| `toggle` | Toggles a collapsible element to shown or hidden. **Returns a promise that resolves once the collapsible element is shown or hidden** (i.e. after the `shown.bs.collapse` or `hidden.bs.collapse` event fires). |
</BsTable>

### Events

Bootstrap’s collapse class exposes a few events for hooking into collapse functionality.

<BsTable>
| Event type | Description |
| --- | --- |
| `hide.bs.collapse` | This event is fired immediately when the `hide` method has been called. |
| `hidden.bs.collapse` | This event is fired when a collapse element has been hidden from the user (will wait for CSS transitions to complete). |
| `show.bs.collapse` | This event fires immediately when the `show` instance method is called. |
| `shown.bs.collapse` | This event is fired when a collapse element has been made visible to the user (will wait for CSS transitions to complete). |
</BsTable>

```js
const myCollapsible = document.getElementById('myCollapsible')
myCollapsible.addEventListener('hidden.bs.collapse', event => {
  // do something...
})
```
